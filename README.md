# Gerenciador de Tarefas

Aplicação web para criar, acompanhar e organizar tarefas, desenvolvida durante os estudos de React.

[![Abrir aplicação](https://img.shields.io/badge/Abrir_aplicação-06B6D4?style=for-the-badge&logo=vercel&logoColor=white)](https://react-orcin-omega.vercel.app/)
[![Código](https://img.shields.io/badge/Ver_código-181717?style=for-the-badge&logo=github&logoColor=white)](https://github.com/marcosloll/React)

## Funcionalidades

- Cadastro de tarefas com título e descrição.
- Marcação de tarefas como concluídas.
- Exclusão de tarefas.
- Página de detalhes para cada tarefa.
- Persistência dos dados no `localStorage`.
- Navegação entre páginas com React Router.

## Executar localmente

1. Clone este repositório.
2. Instale as dependências com `npm install`.
3. Inicie o ambiente de desenvolvimento com `npm run dev`.
4. Abra o endereço exibido pelo Vite no navegador.
